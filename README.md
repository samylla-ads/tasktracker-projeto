TaskTracker

Sistema de gerenciamento de tarefas pessoais, desenvolvido como projeto do Bootcamp II - Análise e Desenvolvimento de Sistemas (CEUB).

Objetivo: ajudar o usuário a organizar suas tarefas diárias de forma simples e centralizada, permitindo cadastrar tarefas com prioridade, visualizar o que está pendente e marcar o que já foi concluído, eliminando a dependência de anotações soltas ou da memória.

Autora: Sâmylla Lohana de Paiva - Análise e Desenvolvimento de Sistemas (ADS), Asa Norte, CEUB
